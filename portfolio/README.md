# Портфолио

Нэг файлтай (`index.html`) энгийн портфолио вэбсайт. Ямар нэг суулгалт хэрэггүй.

## Нээх

`portfolio/index.html` файлыг browser дээр давхар дарж нээнэ.

## Өөрчлөх

`index.html` дотор дараах зүйлсийг өөрийн мэдээллээр солиорой:

- **"Таны Нэр"** болон avatar дээрх **"TN"** үсэг
- **Миний тухай** хэсгийн текст, тоонууд (`data-count`)
- **Ур чадвар** — нэр болон хувь (`data-w`)
- **Төслүүд** — нэр, тайлбар, холбоос
- **Холбоо барих** — имэйл, GitHub, LinkedIn, Instagram холбоос

Өнгийг `<style>` доторх `:root` хэсгийн `--accent` хувьсагчаар солино.
